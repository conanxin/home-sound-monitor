# 使用场景

## 场景一：夜间婴儿监听

晚上孩子睡下后，家长在客厅、书房或卧室活动。每个儿童房已有一个网络摄像头，但家长只需要听声音，不需要一直看画面。

HomeSound 运行在家里的 NAS、小主机或旧电脑上。手机打开本地网页后，就像收听一个家庭内部的“儿童房声音频道”。孩子哭、咳嗽、喊人时，家长能及时听到。

## 场景二：多房间同时监听

家里有两个孩子，分别睡在不同房间。传统方案需要打开两个摄像头 App，或者反复切换房间。

HomeSound 的做法是把多个房间的声音混成一路。家长只听一个音频流，就能知道哪个房间有明显动静。

## 场景三：不想依赖厂商云服务

很多网络摄像头 App 会连接厂商服务器。对一些家庭来说，儿童房声音属于敏感数据，不希望经过第三方平台。

HomeSound 默认面向局域网使用。摄像头、服务端、手机都在家里网络中通信，不需要把音频发到公网。

## 场景四：把旧设备利用起来

家里可能已经有支持 RTSP 的摄像头，也有闲置电脑、树莓派、NAS 或迷你主机。

HomeSound 可以把这些设备组合起来，形成一个简单、可理解、可维护的本地监听系统。
